# 部署上线：从本地到公网

一共四步：**GitHub 建仓库 → 推代码 → Streamlit Cloud 部署 → 生成二维码**。

全程大约 15 分钟，其中等待构建 3 分钟。

---

## 第 0 步：确认本地能跑

```powershell
cd D:\dpwenzhang\shop-orders
.\启动.bat
```

能打开 `http://localhost:8501` 并看到「今日」页，再往下走。

---

## 第 1 步：准备 GitHub

### 1.1 注册 / 登录

没有账号就去 https://github.com 注册（邮箱验证要过）。

### 1.2 建一个空仓库

- 右上角 **+** → **New repository**
- Repository name：`shop-orders`
- 选 **Public**（Private 也行，但 Cloud 免费版读私有仓库要授权）
- **不要**勾 Add a README / .gitignore / license —— 本地已经有了，勾了会冲突
- 点 **Create repository**

建完会看到一个空仓库页面，先别关。

### 1.3 生成访问令牌（Token）

GitHub 2021 年后不接受密码推送，必须用 Token：

1. 右上角头像 → **Settings**
2. 左下 **Developer settings** → **Personal access tokens** → **Tokens (classic)**
3. **Generate new token (classic)**
4. Note 随便写（如 `shop-orders`），Expiration 选 90 天
5. 勾选 **repo**（整个大类）
6. 拉到底 **Generate token**
7. **复制那串 `ghp_...`，只显示一次**

---

## 第 2 步：推代码上去

在 `D:\dpwenzhang\shop-orders` 里执行：

```powershell
git config user.name "你的名字"
git config user.email "你的邮箱"

git remote add origin https://github.com/<你的用户名>/shop-orders.git
git branch -M main
git push -u origin main
```

**推送时会要密码——粘贴刚才那个 `ghp_...` Token，不是 GitHub 登录密码。**

推完刷新仓库页面，应该能看到一堆文件。

> 如果提示 `remote origin already exists`：
> ```powershell
> git remote set-url origin https://github.com/<你的用户名>/shop-orders.git
> ```

---

## 第 3 步：Streamlit Cloud 部署

1. 打开 https://share.streamlit.io
2. 用 **GitHub 账号**登录（必须同一账号）
3. 点 **Create app** → **Deploy a public app from GitHub**
4. 填三项：
   - Repository：`<你的用户名>/shop-orders`
   - Branch：`main`
   - Main file path：**`app.py`**
5. 点 **Advanced settings**（可选）：
   - Python version 选 **3.11** 或 **3.12**（别选太新的，依赖可能没轮子）
6. 点 **Deploy!**

等 2–4 分钟。日志里看到 `You can now view your Streamlit app` 就成功了。

地址形如：`https://shop-orders-xxxx.streamlit.app`

## 第 4 步：生成二维码

把这张图换进汇报页第 12 页（`slides/deck.html` 里搜 `qr_lan.png` 改成 `qr_cloud.png`，再重新打包单文件）。

## 常见错误对照表

| 现象 | 原因 | 处理 |
|---|---|---|
| `ModuleNotFoundError: streamlit` | requirements.txt 不在根目录 | 确认它和 `app.py` 同级 |
| `no such table: sku` | `data/shop.db` 没提交 | 检查 `.gitignore` 有没有排除它；`git ls-files data/` 看得到就行 |
| 构建失败，日志报 numpy/pandas 版本冲突 | Python 版本太新 | Advanced settings 里换 3.11 |
| 打开一直转圈 | 首次构建慢 | 等 3 分钟，或看 Build logs |
| 应用打开后报 `PermissionError` | 云端文件系统只读 | 读没问题；写数据库会失败，属正常（见下） |
| push 报 `Authentication failed` | 用了登录密码 | 改用 Token |
| 二维码扫不开 | 地址写错 / 服务在休眠 | Cloud 免费版闲置会休眠，访问一次唤醒 |

## 两个必须知道的限制

**① 云端的数据是临时的**

Streamlit Cloud 每次重启（闲置 12 小时、或重新部署）会把文件系统重置回仓库状态。也就是说：

- 演示时录的订单、售罄记录，**重启后就没了**
- 这不算 bug，Cloud 本来就是无状态托管

演示当天的做法：提前 10 分钟访问一次唤醒，然后按流程演示。别指望跨天保存。

**② 免费版会休眠**

一段时间没人访问就睡，第一次打开要等十几秒唤醒。演示前务必先自己点一次。

## 退路：局域网

云端出问题时，还有一条路：

```powershell
.\启动.bat
```

手机连同一个 WiFi，扫 `docs/qr_lan.png`（地址要按当天 IP 重新生成）：

```powershell
python scripts/make_qr.py --url http://<你的IP>:8501 --out docs/qr_lan.png --no-url
```

查 IP：`Get-NetIPAddress -AddressFamily IPv4 | Where-Object { $_.IPAddress -notlike '127.*' }`
