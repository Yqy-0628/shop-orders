# 部署上线：从本地到公网（中文界面版）

一共四步：**建仓库 → 推代码 → 云平台部署 → 生成二维码**。

全程约 15 分钟，其中等待构建 3 分钟。

> 说明：GitHub 和 Streamlit 官方界面是英文，浏览器自动翻译后可能显示为中文。
> 下面每个按钮都写成「中文名（English）」，两种界面都能对上。

---

## 第 0 步：先确认本地能跑

```powershell
cd D:\dpwenzhang\shop-orders
.\启动.bat
```

浏览器打开 `http://localhost:8501`，能看到「今日」页再往下走。

## 第 1 步：GitHub 建仓库

### 1.1 登录

打开 https://github.com ，没有账号先注册（要过邮箱验证）。

### 1.2 新建仓库

1. 右上角 **「+」** 号 → **「新建仓库」（New repository）**
2. **「仓库名称」（Repository name）** 填：`shop-orders`
3. 选 **「公开」（Public）**
4. 下面三个勾选项 **全部不要勾**：
   - 添加 README 文件（Add a README file）
   - 添加 .gitignore（Add .gitignore）
   - 选择许可证（Choose a license）

   > 本地已经有这些文件了，勾了会冲突，推不上去。
5. 点 **「创建仓库」（Create repository）**

建完会跳到一个空仓库页面，先别关。

### 1.3 生成访问令牌

GitHub 早就不接受密码推送了，必须用令牌（Token）。

1. 右上角 **头像** → **「设置」（Settings）**
2. 左侧拉到最下 → **「开发者设置」（Developer settings）**
3. **「个人访问令牌」（Personal access tokens）** → **「令牌（经典）」（Tokens (classic)）**
4. 点 **「生成新令牌（经典）」（Generate new token (classic)）**
5. **「备注」（Note）** 随便写，比如 `shop-orders`
6. **「过期时间」（Expiration）** 选 **90 天**
7. **「选择范围」（Select scopes）**：勾选最上面那个 **`repo`**（整大类，勾了会自动带上子项）
8. 拉到最底 → **「生成令牌」（Generate token）**
9. **复制那串 `ghp_` 开头的字符** —— 只显示这一次，关掉就再也看不到

## 第 2 步：把代码推上去

打开 PowerShell，进到项目目录：

```powershell
cd D:\dpwenzhang\shop-orders
```

设置提交者身份（换成你自己的）：

```powershell
git config user.name "你的名字"
git config user.email "你的邮箱"
```

关联远端仓库（把 `<用户名>` 换成你的 GitHub 用户名）：

```powershell
git remote add origin https://github.com/<用户名>/shop-orders.git
git branch -M main
git push -u origin main
```

**推送时会弹窗要账号密码：**

- 用户名：你的 GitHub 用户名
- 密码：**粘贴刚才那个 `ghp_...` 令牌**（不是登录密码，密码框里粘贴不会显示，正常）

推完刷新仓库页面，看到一堆文件就成功了。

> 如果提示「远端已存在」（remote origin already exists），先执行：
> ```powershell
> git remote set-url origin https://github.com/<用户名>/shop-orders.git
> ```

## 第 3 步：Streamlit 云平台部署

1. 打开 https://share.streamlit.io
2. 点 **「继续使用 GitHub 登录」（Continue with GitHub）** —— 必须和上面同一个账号
3. 点右上 **「创建应用」（Create app）**
4. 选 **「从 GitHub 部署公开应用」（Deploy a public app from GitHub）**
5. 填三栏：

   | 栏目（中文） | 栏目（English） | 填什么 |
   |---|---|---|
   | 仓库 | Repository | `<用户名>/shop-orders` |
   | 分支 | Branch | `main` |
   | 主文件路径 | Main file path | `app.py` |

6. 展开 **「高级设置」（Advanced settings）**：
   - **「Python 版本」（Python version）** 选 **3.11** 或 **3.12**

   > 别选 3.13/3.14，依赖可能还没有轮子，构建会失败。

7. 点 **「部署！」（Deploy!）**

等 2–4 分钟。日志里出现 `You can now view your Streamlit app` 就成功了。

页面地址形如：`https://shop-orders-xxxx.streamlit.app`

## 第 4 步：生成二维码

拿到地址后，在本机执行：

```powershell
python scripts/make_qr.py --url https://你的地址.streamlit.app --out docs/qr_cloud.png
```

再把它换进汇报页：打开 `slides/deck.html`，搜索 `qr_lan.png` 改成 `qr_cloud.png`，然后重新打包单文件。

## 常见错误对照表

| 你看到的现象 | 真正原因 | 怎么处理 |
|---|---|---|
| 「找不到模块 streamlit」（ModuleNotFoundError） | `requirements.txt` 不在根目录 | 确认它和 `app.py` 同级 |
| 「没有这个表 sku」（no such table） | `data/shop.db` 没推上去 | 执行 `git ls-files data/`，能看到 `shop.db` 才对 |
| 构建失败，日志报 numpy/pandas 版本冲突 | Python 版本太新 | 高级设置里换成 3.11 |
| 打开一直转圈 | 首次构建慢 | 等 3 分钟，或点「构建日志」（Build logs）看进度 |
| 应用报「权限不足」（PermissionError） | 云端文件系统只读 | 读取没问题；写数据库会失败，属正常，见下 |
| 推送报「认证失败」（Authentication failed） | 用了登录密码 | 改用 `ghp_` 令牌 |
| 二维码扫不开 | 地址写错，或服务在休眠 | 免费版闲置会休眠，先访问一次唤醒 |

## 两个必须提前知道的限制

### ① 云端的数据是临时的

Streamlit 免费版每次重启（闲置 12 小时、或重新部署）都会把文件系统重置回仓库状态。

也就是说：**演示时录的订单、售罄记录，重启后就没了。**

这不是 bug，云平台本来就无状态。演示当天的做法：提前 10 分钟访问一次唤醒，然后按流程演示，别指望跨天保存。

### ② 免费版会休眠

一段时间没人访问就睡，第一次打开要等十几秒。**演示前一定自己先点一次**，别让老师看着转圈。

## 退路：局域网

云端出问题时还有一条路，不需要任何账号：

```powershell
.\启动.bat
```

手机连**同一个 WiFi**，扫码即可。二维码要按当天 IP 重新生成：

```powershell
# 查本机 IP
Get-NetIPAddress -AddressFamily IPv4 | Where-Object { $_.IPAddress -notlike '127.*' }

# 生成二维码（把 IP 换成上一步查到的）
python scripts/make_qr.py --url http://192.168.x.x:8501 --out docs/qr_lan.png --no-url
```

注意：校园网常开「客户端隔离」，两台设备互相访问不了。**最稳的办法是手机开热点，电脑和手机都连热点。**
