# 部署与演示清单

三条路，按顺序试。**第一条成了就用第一条，不成就往下走，别在一条路上耗。**

---

## 路线 A：Streamlit Community Cloud（首选）

**前提**：GitHub 账号 + 能访问 share.streamlit.io（本机已测通，200）。

1. 在 GitHub 新建**空仓库**，名字建议 `shop-orders`，**不要**勾选 README/.gitignore（本地已有）
2. 本地执行（把 `<你的用户名>` 换掉）：

```powershell
cd D:\dpwenzhang\shop-orders
git init
git add .
git commit -m "feat: 小店订货决策台 v1"
git branch -M main
git remote add origin https://github.com/<你的用户名>/shop-orders.git
git push -u origin main
```

3. 打开 https://share.streamlit.io → **New app** → 选仓库 / 分支 `main` / 主文件 `app.py`
4. 点 Deploy，等 2–4 分钟
5. 拿到形如 `https://xxx.streamlit.app` 的地址，**立刻生成二维码**：

```powershell
python scripts/make_qr.py --url https://xxx.streamlit.app --out docs/qr_cloud.png
```

**已知坑**

| 现象 | 原因 | 处理 |
|---|---|---|
| 部署失败，日志报 `ModuleNotFoundError` | `requirements.txt` 没被识别 | 确认它在仓库**根目录**，内容两行 |
| 打开白屏 / 转圈 | 首次构建慢 | 等 3 分钟，或看 Build logs |
| 打开报 `no such table` | `data/shop.db` 没提交 | 确认 `.gitignore` **没有**排除它 |
| 凌晨自动休眠 | 免费额度 | 演示前 10 分钟访问一次唤醒 |
| push 要求 token | GitHub 已禁用密码 | 用 Personal Access Token 当密码 |

**判定**：能拿到地址并且手机能打开 → 走 A，结束。

## 路线 B：局域网 + 二维码（A 不通时的主力）

同一个 WiFi 下，手机直接访问你电脑上的服务。

```powershell
# 1. 查本机 IP（WLAN 那一行的 IPv4）
Get-NetIPAddress -AddressFamily IPv4 | Where-Object { $_.IPAddress -notlike '127.*' }

# 2. 启动（这个 bat 会自动开浏览器）
.\启动.bat
```

3. 生成局域网二维码：

```powershell
python scripts/make_qr.py --url http://192.168.x.x:8501 --out docs/qr_lan.png
```

**注意**

- 手机和电脑必须在**同一个 WiFi**；校园网常开"客户端隔离"，会导致互 ping 不通 → 用手机热点，两台设备连热点
- Windows 防火墙第一次会弹窗，**必须点"允许"**（专用网络）
- 电脑不能睡眠：设置 → 电源 → 屏幕和睡眠 → 全部设为"从不"

**判定**：手机连热点后能打开 → 走 B，够用。

## 路线 C：纯本地 + 录屏（兜底）

现场如果网络彻底不行：

1. 本地跑 `启动.bat`，投屏演示
2. 提前录一段 **60 秒**的完整闭环（开单 → 售罄 → 决策台拖滑块 → 生成订货单），存成 mp4
3. 二维码换成"演示视频"或直接不放

**录屏怎么录**：Win + G 打开 Xbox Game Bar → 捕获 → 录制。或者用 PowerPoint 的"屏幕录制"。

## 演示当天检查表

**提前一天**

- [ ] 路线选定了，地址能用手机打开（用别人的手机试，别用自己的）
- [ ] 二维码已生成，打印或存进 PPT 第一页
- [ ] 断网状态下能本地跑通一遍（拔网线试）
- [ ] `启动.bat` 双击能起来（别现场才试）

**提前 10 分钟**

- [ ] 服务已启动，浏览器已打开，**停在首页**
- [ ] 试开一单、点一次售罄、拖一次滑块——确认没报错
- [ ] 音量关掉，通知关掉（Win + A → 专注助手 → 仅闹钟）
- [ ] 投影分辨率确认：16:9 还是 4:3

**现场**

- [ ] 先放二维码让大家扫，再开始讲
- [ ] 演示顺序：开单 → 售罄 → 决策台 → 回放 → 权限
- [ ] 任何一步卡住超过 5 秒：直接说"这个我们跳过"，继续往下讲

## 一句话

**能上云就上云；上不了就用局域网 + 热点；两个都不行，就用录屏。三条路都要提前跑一遍，不要现场第一次试。**
