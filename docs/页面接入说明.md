## 一个页面长什么样（骨架）

```python
import streamlit as st
import ui
from core.api import predict, suggest, record_decision

ui.page("订货", "📦")
user = ui.guard()

sku = st.session_state.get("sku_id", "饮品01")

p = predict(sku)
st.metric("明天预计", f"{p['value']} 件",
          help=f"90% 区间 {p['lo']} – {p['hi']}")

with st.expander("为什么是这个数"):
    for e in p["explain"]:
        st.write(f"{e['label']}：{e['value']}")

s = suggest(sku)
cols = st.columns(3)
for c, t in zip(cols, s["tiers"]):
    with c:
        st.subheader(t["name"])
        st.metric("订多少", f"{t['qty']} 个")
        st.caption(f"报废 {t['waste']}｜断货 {t['stockout']*100:.0f}%")
        if st.button("选这档", key=t["key"]):
            record_decision(sku, t["qty"])
            st.success("已下单")
```

**关键：页面里不出现任何计算。** 所有数字都来自 `core/api.py`。
